Technology Focus

B1 Vocabulary & Expression Study Guide

Vocabulary Cloze Expressions Cloze
1. Systems & Operations
Access v. / n.
To log into, open, or enter a system, file, or database.
Example 1 "I can't access the shared folder from home."
Example 2 "Do you have access to the company financial records?"
Update / Upgrade v. / n.
Update: Patching software. Upgrade: Replacing with a newer/better model or version.
Example 1 "Remember to update your antivirus software regularly."
Example 2 "We plan to upgrade all office laptops next quarter."
Backup v. / n.
To save a copy of data in a separate location to prevent data loss.
Example 1 "Make sure to back up your files before turning off your PC."
Example 2 "We store our daily backups on an external drive."
Storage / Memory n.
Storage: Space for files (SSD/Cloud). Memory (RAM): Power to run apps simultaneously.
Example 1 "My phone is running out of cloud storage."
Example 2 "This software requires at least 16GB of RAM memory to run smoothly."
Compatible adj.
Able to work together without system errors or technical conflicts.
Example 1 "This app isn't compatible with older operating systems."
Example 2 "Check if the printer is compatible with your wireless router."
2. Connectivity & Cloud
Bandwidth n.
The capacity or speed at which data travels over an internet connection.
Example 1 "Video calls take up a lot of bandwidth."
Example 2 "We need to increase our bandwidth to handle larger uploads."
Cloud-based adj.
Stored, managed, or processed on remote internet servers rather than locally.
Example 1 "We switched to a cloud-based email provider."
Example 2 "Our team uses cloud-based software so we can work remotely."
Sync (Synchronize) v.
To automatically update data across multiple devices so they match.
Example 1 "My calendar syncs automatically with my phone."
Example 2 "Give the folder a minute to sync all the new files."
Outage / Downtime n.
A period when a technical system, power, or internet service is unavailable.
Example 1 "An unexpected power outage shut down our local servers."
Example 2 "The website will experience scheduled downtime for maintenance tonight."
3. Security & Settings
Credentials n.
Login information used to verify a user (usernames, passwords, security keys).
Example 1 "Never share your login credentials over email."
Example 2 "Enter your credentials to access the secure portal."
Permissions n.
Access rights granted to specific users to view, edit, or delete files.
Example 1 "You need administrative permissions to install this program."
Example 2 "I adjusted the folder permissions so clients can only view documents."
Default Settings n.
The pre-configured options assigned to a device or software out of the box.
Example 1 "If you make a mistake, you can reset the app to its default settings."
Example 2 "Change the default password as soon as you turn on the router."
4. Explaining Technical Glitches
It keeps [freezing / crashing / buffering].
Example 1: "My screen keeps freezing every time I open this spreadsheet."
Example 2: "The application crashed while I was saving the report."
It's running really slowly today.
Example 1: "My browser is running really slowly today; it takes a minute to load a page."
Example 2: "The computer is running slowly because you have twenty tabs open."
I'm getting an error message that says...
Example 1: "I'm getting an error message that says 'File Not Found'."
Example 2: "When I click submit, I get an error message that says my session expired."
The connection keeps dropping.
Example 1: "I can't finish the call because the connection keeps dropping."
Example 2: "Our Wi-Fi connection keeps dropping whenever it rains."
5. Troubleshooting & Instructions
Try restarting / rebooting the system.
Example 1: "Before calling IT, try restarting the system."
Example 2: "Rebooting the server usually fixes minor network glitches."
Clear your browser cache and cookies.
Example 1: "If the web page won't load properly, clear your browser cache."
Example 2: "Clearing your cache and cookies can resolve login issues."
Double-check your credentials.
Example 1: "Double-check your credentials to ensure your cap lock isn't on."
Example 2: "If it fails to log in, double-check your credentials with the administrator."
6. Specifying & Recommending Specs
It's a bit pricey upfront, but...
Example 1: "It's a bit pricey upfront, but it's more cost-effective in the long run."
Example 2: " buying quality hardware is a bit pricey upfront, but it saves maintenance costs later."
It has enough processing power for...
Example 1: "It has enough processing power for basic video editing."
Example 2: "This entry-level chip has enough processing power for our daily admin tasks."
Is it worth the extra cost?
Example 1: "Is the upgraded phone model really worth the extra cost?"
Example 2: "We need to ask ourselves if faster shipping is worth the extra cost."
